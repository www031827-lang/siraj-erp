# 🌟 نظام سراج ERP

نظام متكامل لإدارة المؤسسات (ERP) مبني على خادم خاص و 5 تطبيقات Android (قابلة للتوسع ديناميكياً).

## 💡 رؤية النظام
"سراج" هو نظام إداري متكامل يهدف إلى توفير بيئة عمل رقمية آمنة، مرنة، وقابلة للتخصيص، تغطي جميع جوانب المؤسسة من المبيعات والمخزون إلى الإنتاج والمالية، تحت إشراف المدير العام.

## 🚀 الميزات الرئيسية
- 👤 إدارة ديناميكية للمستخدمين والصلاحيات (RBAC).
- 💰 محاسبة دقيقة تعتمد على دفاتر الحركات (Ledger) وليس الأرصدة الجاهلة.
- 📱 Offline First: اعمل دون إنترنت، ثم قم بالمزامنة تلقائياً.
- 🏪 متجر تطبيقات خاص لتوزيع التحديثات وإضافة تطبيقات جديدة (دون تعديل الكود الأساسي).
- 🔐 أمان متعدد الطبقات (بصمة، وجه، كلمة مرور، صلاحيات على مستوى الخادم).
- 📊 لوحة تحكم للمدير العام تشمل جميع التقارير الموحدة وسجل التدقيق (Audit Log).

## 📂 هيكل المشروع
- `/android` : تطبيقات الأندرويد الخمسة (المدير العام، المالي، المبيعات، المواد الخام، الإنتاج).
- `/server` : خادم API (جاهز للتطوير بـ Laravel / Node.js).
- `/database` : ملفات هيكل قاعدة البيانات (MySQL/MariaDB).
- `/docs` : وثائق النظام وواجهات API.
